# Assets and dependency licenses

Checked against the installed dependency metadata and upstream terms on 2026-09-19. `package-lock.json` pins the JavaScript dependency graph; `pipeline/requirements-lock.txt` records the tested Python environment. The tool does not bundle stock music, commercial icon packs, logos or third-party SFX. Original procedural SFX and original test SVG/Lottie artwork in this repository are dedicated under CC0-1.0. User media remains user-owned and must be licensed for the intended distribution.

All per-video assets must be declared in `graphics-plan.json.assets` with ID, project-relative path, kind, license and credit. Lottie files must embed images, bake expressions and outline text; no live network assets are permitted. No external icons are needed: annotations are original SVG geometry. Font fallbacks are declared for browser resilience, but final renders wait for local files; missing files fail rendering. The bundled Latin subsets suit the default English workflow. Add and test appropriate OFL subsets in the engine before producing other scripts.

## Additional typography families

DM Sans, Playfair Display, Montserrat, Anton, Poppins, Great Vibes, Anek Latin, Bebas Neue and Instrument Serif are bundled from their pinned Fontsource packages under SIL OFL 1.1. Each font has its own `<family>-OFL.txt` notice under `public/fonts`; the family, weight and file mappings are explicit in `src/tokens/typography.ts`. Inter Regular and Black extend the existing OFL Inter bundle. All nine added families use OFL terms, and only the selected pairing plus the mono face loads for a render. See [the pairing register](typography.md) for which requested proprietary faces are substituted. No SF Pro, Gilroy, Coolvetica or Headliner binary is bundled or implicitly licensed by this project.
