# FFmpeg reference commands

The CLI uses argument arrays instead of shell-interpolating paths. These shell examples quote paths for manual operation. Replace filenames with your paths.

Probe metadata and frame timing (the ingest script additionally hashes every source byte and checks per-frame timestamp deltas):

```sh
ffprobe -v error -show_streams -show_format -of json 'locked.mov'
ffprobe -v error -select_streams v:0 -show_frames \
  -show_entries frame=best_effort_timestamp_time,pkt_duration_time,duration_time \
  -of json 'locked.mov'
```

FFmpeg scene-filter alternative to PySceneDetect; timestamps appear in showinfo logs. Use them as candidates and inspect each boundary:

```sh
ffmpeg -i 'locked.mov' -vf "select='gt(scene,0.30)',showinfo" -an -f null -
```

Loudness measurement (no source mutation):

```sh
ffmpeg -i 'locked.mov' -map 0:a:0 \
  -af 'loudnorm=I=-14:TP=-1:LRA=11:print_format=json' -f null -
```

Graphics-only alpha pass (props file is generated by `mg preview` or staging in `render`):

```sh
npx remotion render src/index.ts Overlay 'overlay.mov' \
  --props='projects/my-video/render-props.json' \
  --codec=prores --prores-profile=4444 --image-format=png --pixel-format=yuva444p10le
```

Final H.264 High composite, original audio stream copy. The CLI also sets the exact source frame count and preserves known source color metadata. MOV allows PCM source audio to remain unchanged:

```sh
ffmpeg -i 'locked.mov' -i 'overlay.mov' \
  -filter_complex '[0:v:0][1:v:0]overlay=0:0:format=auto:eof_action=pass:repeatlast=0[v]' \
  -map '[v]' -map '0:a?' -map_metadata 0 \
  -c:v libx264 -profile:v high -crf 17 -pix_fmt yuv420p \
  -fps_mode passthrough -c:a copy -movflags +faststart 'composite.mov'
```

Optional ProRes 422 HQ composite (new encoding, same temporal edit):

```sh
ffmpeg -i 'locked.mov' -i 'overlay.mov' \
  -filter_complex '[0:v:0][1:v:0]overlay=0:0:format=auto:eof_action=pass:repeatlast=0[v]' \
  -map '[v]' -map '0:a?' -map_metadata 0 -c:v prores_ks -profile:v 3 \
  -pix_fmt yuv422p10le -fps_mode passthrough -c:a copy 'composite-prores-hq.mov'
```

Optional MP4 rewrap for compatible source audio such as AAC (the main delivery remains MOV to support lossless audio passthrough):

```sh
ffmpeg -i 'composite.mov' -map 0 -c copy -movflags +faststart 'composite.mp4'
```

If the audio codec is not MP4-compatible, keep MOV or explicitly opt into a separate AAC export. Never silently re-encode audio merely to change the extension. `audio.mode=normalize` and `audio.mode=sfx` intentionally change the mix; the pipeline measures a first loudnorm pass, applies a second pass, and verifies the resulting loudness. It emits a normalized PCM mix plus dry and ducked SFX stems when enabled. Sidechain ducking uses the provided mixed audio, not a separately isolated dialogue track. Keep effects quiet and listen to the result.

## Export defaults

| Target | Frame size | Frame rate | Video / audio |
| --- | --- | --- | --- |
| YouTube 4K | 3840×2160 source | Exact source 24/30/60 or rational rate | H.264 High CRF 17, yuv420p; source audio copy by default |
| YouTube 1080p | 1920×1080 source | Exact source | Same; reserve end-screen zones in final 20 seconds |
| Shorts / Reels / TikTok | 1080×1920 source | Exact source | Same; platform safe area from tokens |
| NLE graphics layer | Exact source dimensions | Exact source | ProRes 4444, PNG rendering, yuva444p10le encoder input; probe may report decoded yuva444p12le |

These are configurable delivery defaults, not claims that every platform mandates a particular LUFS target. The optional remix target is -14 LUFS / -1 dBTP, with 1 LU tolerance checked. Never convert a landscape locked edit into portrait automatically: create a separately approved portrait master and initialize a separate project. SDR progressive square-pixel inputs only. VFR/HDR/interlaced/rotated sources stop with an explanation instead of silently conforming.
